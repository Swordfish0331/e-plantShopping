# Paradise Nursery 🌿

**Paradise Nursery** is a front-end shopping application built with React and Redux Toolkit. Browse a curated collection of houseplants organized by category, add them to your cart, and manage your order before checkout.

## Project Name
**e-plantShopping** — Paradise Nursery Plant Shop

## Features
- Landing page with company overview and "Get Started" CTA
- Product listing page with 6+ plants across 3+ categories
- Add to Cart functionality with disabled state after adding
- Shopping cart with quantity controls (increase/decrease/delete)
- Dynamic cart item count displayed in navbar
- Total cost calculation updated in real time
- Continue Shopping and Checkout buttons
- Deployed via GitHub Pages

## Tech Stack
- React 18
- Redux Toolkit
- React Router DOM
- Vite

## Getting Started

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
npm run deploy
```

## Pages
- `/` — Landing Page
- `/plants` — Product Listing
